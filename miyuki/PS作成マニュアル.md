## 1. 全体の流れ

```
本鑑定文 ──┐
本鑑定構成 ┼─→ ①PS文(txt) ─→ ②PSページ(HTML) ─→ ③返信文に詳細URL ─→ ④URL登録
無料鑑定メモ┘      ↑
        テンプレ＋参考PS文
```

**材料（先に全部読む）**
1. `連番_名前_本鑑定文.txt`：合図の言葉、守護神、時期、お客様の暮らしの場面
2. `連番_名前_本鑑定構成.txt`：⑥の候補の石3つ、合図の言葉
3. `無料鑑定メモ.txt`：オーラの色、お子さんなど家族の情報
4. `追加質問.txt`（あれば）：お客様の返信で新しく出た情報
5. `深雪_PSテンプレート.txt`：型
6. 参考PS文：`1662_でぃあ_PS.txt`（最新）、`1616_みゆき_PS.txt`

> 本鑑定文の「⛩️あなたと響き合うパワーストーン」で出した候補の石3つと、PS文の石3つは**必ず同じ**にする。

## 2. ① PS文（txt）を作る

### 保存先
`有料鑑定/深雪/連番_名前様_本式守護鑑定/連番_名前_PS.txt`

### 構成（テンプレそのまま。順番も見出しも変えない）
```
━━━ （区切り）
【名前】様
詳細のご希望、ありがとうございます。…
━━━
💎 【名前】様専用パワーストーンについて
━━━
🪨 3つの石について
━━━
✨ 【名前】様専用ブレスレット　価格：29,800円
━━━
⏰ タイミングについて
━━━
📦 お届けについて（固定文）
━━━
🎁 ご購入特典（固定文）
━━━
購入リンク（固定URL）
お値段のことは、…（固定文）
結びの言葉
深雪
```
📦 お届けについて／🎁 ご購入特典／購入リンクは**固定文**。1662からそのままコピーする。

### 各パートの中身

**💎 専用パワーストーンについて**
1. 「命の流れを視させていただき、今の◯◯様に最も必要な石を3つ選びました」（固定）
2. 本質・強み：その人の暮らしの場面で書く（1662なら「型紙を一本ずつ引いてきた手」「子どもたちの分を先に数え終える」）
3. 「でも、」から課題：**日常の場面で書く**（1662なら「月末にお財布を開いて…」）
4. 今後の流れ：本鑑定文の時期と**同じ表現**にする。新しい時期を足さない
5. 「その流れを最大限に活かすために、◯◯様のエネルギーと守護神名（読み方）が深く共鳴する3つの石を選びました」

**🪨 3つの石**
- 石ごとに `---` で区切る
- 並びと役割（テンプレのとおり）：
  - 石1：その人の持つエネルギーと共鳴する石。課題の場面で声や行動を支える
  - 石2：**守護神と最も共鳴が強い石**。「その守護を日常の中でずっとそばに置いておける石です」
  - 石3：自責・ループをほどく石。オーラの色と重ねてよい
- 1行目は色や光の描写（例：朝焼けのような橙を宿した）
- 本鑑定文の**合図の言葉**につなげる。本文に出ていない新しい行動を石の説明の中で足さない
- 守護神と石を結ぶ神話・来歴は書かない

**✨ ブレスレット**
- 価格は29,800円（固定）
- 「身につけていくうちに、◯◯という感覚が少しずつ戻ってきます」（◯◯は合図の言葉に近い、その人の言葉）
- 揺らぎの場面を1〜2つ → 「石が静かにそのループをほどいてくれる」
- 「日常の中で、守護がそばにある。」（固定）
- 重要な時期に向けて整った状態で臨めること

**⏰ タイミング**
- 「通常2〜3週間ほどかかります」（固定）
- 「今から始めることで、◯◯を迎える頃にはエネルギーが整った状態になります」
- **時期は本鑑定文の時期と揃える。** 1662で「11月前提」の表現を立春基準に直した（commit 5d4e9ec）ように、送付日と時期がずれていないか確認する

**結び**
- 相談内容に沿った締めの一言。お客様の暮らしの絵で終わる（1662なら「湯気の立つお椀をご自分の手で受け取る日々」）
- 署名は `深雪`

### 書いてはいけないこと
| NG | 理由 |
|---|---|
| 「守護の力が薄れていく」「戻ると縁が遠のく」「この石がないと」 | 不安をあおる形は消費者契約法で取り消し対象。癖が戻るのは霊視ではなく**日常の事実**として書く |
| 「お早めに」「今だけ」「残りわずか」 | 煽り |
| 「──」を間や挿入句に使う | 禁止。テンプレの「でも──」は「でも、」に直す |
| 「性（さが）」表現 | 使わない。直接描写で書く |
| 「こんな経験はありませんでしたか？」 | 使わない。断定で書く |
| 「◯◯ってLINEで送ってみてください」 | LINE文面例は入れない |
| 石を性格傾向だけに紐づける | 妊娠中、月末の家計など**具体的な状況**に紐づける（転換率が違う） |
| 名前の連呼 | 頻度は控えめに（無料鑑定ルールに準拠） |

### 書き方のトーン
- 1行は短く。読点・句点で改行し、1ブロックは3〜6行
- 前半（💎）は具体的に、石・祈祷・時期のあたりはスピリチュアル濃度を上げる
- 守護神名は初出で読み仮名：`豊受大神（とようけのおおかみ）`

### 保存前チェック
- [ ] 候補の石3つが本鑑定文と一致
- [ ] 合図の言葉・時期が本鑑定文と一致
- [ ] 守護神名の表記・読み仮名が本鑑定文と一致
- [ ] 【】のプレースホルダが残っていない
- [ ] 「──」「性（さが）」がない
- [ ] 署名が `深雪`（かな の署名になっていない）

## 3. ② PSページ（HTML）を作る

### 手順（自動）
PS文txtを保存したら、これを実行する（Claudeが実行する。人は動かさない）：

```bash
python3 miyuki/make_ps_html.py 有料鑑定/深雪/連番_名前様_本式守護鑑定/連番_名前_PS.txt
```

これで次の3つが一度に済む：
1. `miyuki/連番_名前様PS/index.html` を作る（CSS・`<title>`・フッターは1662のひな形から自動で取る）
2. 検査する：石の画像が実在するか、`【】` が残っていないか、`──` や「性（さが）」がないか、価格・購入URL・署名があるか、石名が認識できるか。1つでも引っかかるとHTMLは作らずエラーを出す
3. `miyukihonshiki.txt` に `PS` のURL行を追記する（すでにあれば何もしない）。返信文に入れるURLも出力する

動作確認済み：1662・1616のtxtから作ったHTMLの本文は、手作りの既存HTMLと一致した（改行位置の違いは除く）。1524は、画像のないパイライトでエラーになる。

> HTMLの改行はtxtの改行のとおりになる。手でHTMLだけ直すと、txtとズレる。直すときは**txtを直して再実行**する。
> 連番とお客様名が同じフォルダは上書きされる。

### txt → HTML 変換ルール（スクリプトの中身。1662で確認済み）
| txt | HTML |
|---|---|
| 空行で区切られた1ブロック | `<p>行1<br>行2<br>行3</p>`、ブロックの間は `<br>` |
| `━━━` | `<hr class="divider">` |
| `💎`／`🪨`／`✨`／`⏰`／`📦`／`🎁` で始まる行 | `<div class="section-title">…</div>` |
| 石の名前の行 | `<div class="stone-title">石名</div>` ＋ `<img src="../素材/ファイル名.png" class="stone-img" alt="石名">` |
| `---`（石と石の間） | `<div class="stone-divider"></div>` |
| `価格：29,800円` | `<div class="price-box"><div class="price-label">◯◯様専用ブレスレット</div><div class="price-num">¥29,800</div><div class="price-tax">（税込）</div></div>` |
| 📦のリスト | `<ul class="info-list"><li>…</li></ul>` |
| 🎁のリスト | `<div class="tokuten"><ul><li data-num="1">…</li>…</ul></div>` |
| 購入URL | `<a href="URL" class="cta-button" target="_blank" rel="noopener">ブレスレットを希望する</a>` ＋ `<p class="cta-note">※ 別ウィンドウで購入ページが開きます</p>`（その前に「ご希望の方は、下のボタンよりお進みください。」） |
| 結びの言葉＋署名 | `<div class="closing"><p>…</p><div class="closing-sign">深雪</div></div>` |

- 💎の2つ目の「…ブレスレット」セクションのタイトルの直後に price-box が入る（txtの価格行は本文に出さない）
- 購入URLは**CTAボタンになるので本文にURLの文字は出さない**
- 📦・🎁・CTA周辺は固定。1662からそのまま使い回す

## 5. ④ URL登録

**§3のスクリプトが自動で追記する。** 手でやる必要はない。仕組みの参考として、`miyuki/miyukihonshiki.txt` の末尾に1行追加される。形式は `PS` ＋ URL：

```
PShttps://kantei-pdf.pages.dev/miyuki/1662_%E3%81%A7%E3%81%83%E3%81%82%E6%A7%98PS/
```

URLの作り方：
```bash
python3 -c "
import urllib.parse as u
print('PS' + 'https://kantei-pdf.pages.dev/miyuki/' + u.quote('連番_名前様PS') + '/')"
```
（本鑑定の行は先頭が `有料`。PSは `PS`）

### 一言CSV（`miyuki_hitokoto.csv`）の文字コード

`make_hitokoto.py` が出力するCSVは **UTF-8 BOM付き（`utf-8-sig`）**。BOMなしだとMacのExcel／Numbersで文字化けする。スクリプトを直すときも読み書きとも `utf-8-sig` を保つこと（`special/make_hitokoto.py` も同様）。
